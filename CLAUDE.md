# gtm-engineer-portfolio

My GTM Engineer training work, program v12.1 (builder track).

## Layout
- docs/lesson-NN/   notes, diagrams and evidence for each lesson
- labs/             hands-on builds (labs/hubspot-client is Lessons 2-3)
- projects/         flagship work until each project gets its own repo
- README.md         index of everything in the repo

## Stack
Hosted n8n, HubSpot developer test account (Service Key), Salesforce Developer Edition, Supabase Postgres, Clay, Claude API. Python 3.12 in a .venv.

## Repo rules
- Commit messages start with the lesson number, like "L02: read a contact with the Service Key".
- Each lesson's evidence goes in docs/lesson-NN/ and gets linked in my tracker.
- Label every result synthetic, sandbox-tested or self-measured.
